### 🚀 Projeto em destaque

<div align="center">

<table>
<tr>
<td width="100%">

#### 🩺 VisAll — SaaS multi-tenant

Plataforma completa de gestão de propagandistas: agendamento, visitas, metas,
estoque, simulação de ausências e sincronização com ERPs externos.

- **API** — `NestJS 11` · `Drizzle ORM` · **arquitetura multi-tenant com schema por cliente**
- **Dados** — `PostgreSQL` + integrações `MySQL` / `MSSQL` / `Snowflake`
- **Async** — filas `BullMQ` + jobs agendados (`@nestjs/schedule`) + `WebSockets` em tempo real
- **Mobile** — `Expo / React Native 19` **offline-first** com `WatermelonDB` + fila de sync
- **Infra** — `AWS S3/SQS` · `Firebase` push · exportação `Excel/CSV` · `LiveKit`
